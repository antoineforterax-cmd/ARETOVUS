- [Licences et droits](LICENCES_ET_DROITS.md) : MIT OR Apache-2.0, forks, attribution et contributions assistées par IA.
- [Guide de contribution officiel](../../CONTRIBUTING.md).
- [Instructions de maintenance](../../AGENTS.md), [politique d'implémentation](../planning/IMPLEMENTATION_POLICY.md).
- [Signaler une faille](../../SECURITY.md).
