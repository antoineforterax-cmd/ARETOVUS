# ARETOVUS — identité native de protocole

Le logo et le nom de marque utilisent ARETOVUS. La branche expérimentale native ne se limite plus à un habillage visuel : **la genèse, les domaines cryptographiques, le stockage, les formats de clés et les demandes de paiement font partie du nouveau réseau ARETOVUS**.

Cette opération est une rupture de compatibilité volontaire. Ne pas ouvrir les archives du testnet précédent avec le nouveau binaire. Aucun solde ancien n'est transféré automatiquement, et aucun fichier historique ne doit être supprimé.

Pour les détails exacts, les nouveaux magic bytes, les identifiants de genèse et les critères de tests : [PROTOCOL_IDENTITY_MIGRATION.md](PROTOCOL_IDENTITY_MIGRATION.md).

Le logo SVG reste [ici](../assets/aretovus-logo.svg) et n'intervient dans aucune opération cryptographique. Les anciennes éditions des binaires et l'historique Git sont conservés comme preuves d'essais passés et ne sont pas des versions courantes de cette nouvelle chaîne.
